# libasn1compiler_go — the asn1c Go backend

`asn1c -Fgo=<dir>` generates Go types and APER `Encode` / `Decode` functions
for your ASN.1 specification. The Go code calls the C codec that the same
`asn1c` run writes, through cgo, so the output always matches the C backend's
view of the specification. Requirements: Linux amd64, Go 1.21 or newer, cgo
enabled and a C compiler. Known bugs and open limitations are in
[KNOWN-ISSUES.md](KNOWN-ISSUES.md). The generated code's error model is
described in the runtime module's README (`rt/go/README.md`).

## Build

```sh
autoreconf -fi && ./configure CC=gcc 'CFLAGS=-O1 -g' && make
```

The binary is `asn1c/asn1c`.

## Generating Go

```sh
asn1c -S <fork>/skeletons -fincludes-quoted -fcompound-names \
      -findirect-choice -fno-include-deps -gen-PER -no-gen-OER -pdu=auto \
      -D <c-outdir> -Fgo=<go-outdir> <spec.asn...>
```

Run it as a binary named `asn1c` (or through `exec -a asn1c`): asn1c stamps its
command line into every generated file, and a stable argv keeps the output
reproducible.

`-no-gen-OER` is the supported configuration. Trees generated with OER on also
build and work for APER; the generated Go API is APER-only.

**Module path.** The Go module path is
`<ASN1CGO_GO_MODULE_PREFIX>/<basename of the -Fgo dir>`, or just the basename
when no prefix is set. `-Fgo=out/go` with prefix `your.prefix` gives module
`your.prefix/go`, imported as `your.prefix/go/<package>`. Without a prefix the
basename must not be a top-level Go standard-library path element (`go`, `net`,
`os`, `math`, ...) or `std`, `cmd`, `all`: a module named `go` would import its
packages from inside the standard library. asn1c refuses it with exit 70.

**go.mod and go.work.** The generated `go.mod` requires the runtime module at
the generator's version (see Runtime module). Run `go mod tidy` once in the
generated directory to fetch it and write `go.sum`; with
`ASN1CGO_RT_LOCAL=<dir>` the `go.mod` instead gets a `replace` to a local
runtime checkout and no fetch is needed. When `-Fgo` has a parent directory
(`out/go`), the generator also adds the module to `out/go.work` (created if
absent). Generators running in parallel into sibling directories are
serialised by a lock file `<parent>/.go.work.lock`.

**Output layout.** `-Fgo=<dir>` writes `go.mod`, one Go package per ASN.1
module (`<module>_dir`, lowercased, `-` replaced by `_`) with the `Encode` /
`Decode` API per PDU type, and the C sources the packages build under
`<dir>/internal/cspec` and `<dir>/c`. Every `.go` file starts with
`// Code generated by asn1cgo. DO NOT EDIT.`. The generator emits valid but
unformatted Go; run `gofmt -w` over the tree.

**All-or-nothing output.** The Go tree is built in a hidden staging directory
next to `<dir>` and swapped in only when generation succeeded. On failure
`<dir>` is left as it was, asn1c prints `asn1cgo: ...` lines and exits 70.
`<dir>` is replaced as a whole, so files that are no longer produced disappear
and **anything you keep in `<dir>` is deleted**: put hand-written code in a
separate module that imports the generated one. A hidden
`.<basename>.asn1cgo-tmp-*` directory left by a killed run is safe to delete.

**The C and Go outputs are not updated atomically.** asn1c writes the C code
into `-D` before the Go pass runs. Refusals that do not depend on the C pass
(unsupported constructs, unsupported DEFAULT forms, an invalid module prefix or
basename, a standard-library basename) are detected first and leave `-D`
untouched (`no C output was written`). Name collisions, by-value type cycles
and I/O errors are detected after the C pass: then `-D` holds the new C code
while `<dir>` is still the previous generation. Fix the error and regenerate
both; never build the old Go tree against the new C output.

## Using the generated code

For each PDU type the generated package exports exactly:

```go
func (p *<PDU>) Encode() ([]byte, error)   // APER bytes
func Decode<PDU>(b []byte) (*<PDU>, error) // APER bytes -> value
```

Example specification (a SEQUENCE, a nested CHOICE, an OPTIONAL member):

```asn.1
Synth-Example DEFINITIONS AUTOMATIC TAGS ::=
BEGIN

Example-PDU ::= SEQUENCE {
    requestId   INTEGER (0..65535),
    payload     Example-Payload,
    note        PrintableString (SIZE(1..32)) OPTIONAL,
    ...
}

Example-Payload ::= CHOICE {
    text        PrintableString (SIZE(1..32)),
    number      INTEGER (0..255),
    ...
}

END
```

It generates the package `synth_example` with

```go
type ExamplePDU struct {
    RequestId int64
    Payload   ExamplePayload
    Note      *string          // OPTIONAL: nil = absent
}
type ExamplePayload struct {
    Present ExamplePayloadPr   // discriminant
    Text    *string
    Number  *int64
}
```

and a value round-trips like this (with `-Fgo=<dir>/go` and
`ASN1CGO_GO_MODULE_PREFIX=your.prefix`):

```go readme-example
package main

import (
    "fmt"

    ex "your.prefix/go/synth_example"
)

func main() {
    v := &ex.ExamplePDU{
        RequestId: 7,
        Payload: ex.ExamplePayload{
            Present: ex.ExamplePayloadPrNumber,
            Number:  ptrTo(int64(42)),
        },
    }
    wire, err := v.Encode()
    if err != nil {
        panic(err)
    }
    back, err := ex.DecodeExamplePDU(wire)
    if err != nil {
        panic(err)
    }
    fmt.Println(back.RequestId, *back.Payload.Number)
}

func ptrTo[T any](v T) *T { return &v }
```

Values are ordinary Go struct trees: slices and pointers, no handles, nothing to
free.

**Errors.** Failures are `*rt.Error` values that match the sentinels with
`errors.Is` (see `rt/go/README.md`).

| Code | Encode | Decode |
|------|--------|--------|
| `ErrArg` | nil receiver | **nil or empty input** |
| `ErrAlloc` | yes | yes |
| `ErrConstraint` | value outside a declared range/size/alphabet | decoded value violates a constraint |
| `ErrEncode` | the APER encoder failed (including its own out-of-memory) | never |
| `ErrDecode` | never | malformed bytes, including an IE id the spec's object set does not list; also a C stack guard trip (see Platform and limits) |
| `ErrTrailing` | never | bytes left after the PDU |
| `ErrChoiceNothing`, `ErrChoiceBad` | a CHOICE with no / an invalid `Present` | defensive only |
| `ErrIOCUnknown` | the IE id is not in the governing object set | defensive only |
| `ErrIOCMismatch` | the id is known, but `Present` is not the alternative it governs | defensive only |
| `ErrDepth` | recursion budget exceeded | recursion budget exceeded |
| `ErrInternal` | a generator or runtime bug, never caused by caller input; please report it with the spec | same |

**IE constructors.** For a spec whose IE lists are governed by an Information
Object Class and object set (3GPP style), the package also emits one
constructor per object-set row, named `New` + record type + row id value
reference (Go-cased), e.g. `NewExampleIEsIdExampleID(v ExampleType) ExampleIEs`.
It fills the record's dispatch fields (id, the value union's `Present`, other
row-governed fields) from the spec row. `Encode` writes whatever the fields
hold and `Decode` returns them as received; neither checks them against the
row. A spec without object sets gets no constructors.

**Recursion depth.** Encode and decode charge a budget of 64 depth units per
call (one per entry into a recursive type), so a recursive ASN.1 level nested
through several types can cost several units. Past the budget the call fails
with `rt.ErrDepth`.

## ASN.1 to Go mapping

| ASN.1 | Go |
|---|---|
| BOOLEAN | `bool` |
| INTEGER | `int64`; for a range that does not fit a C `long`: `uint64` (lower bound >= 0, upper <= 2^64-1) or `int64`. A range that fits neither is refused |
| ENUMERATED | `type <T> int32` plus one constant per enumerator |
| REAL | `float64` |
| NULL | `struct{}` |
| BIT STRING | `BitString` (`type X BitString` when named). Named bits add `int` position constants `<GoType><Bit>` |
| OCTET STRING | `[]byte` |
| Restricted strings, UTCTime, GeneralizedTime | `string`; BMPString and UniversalString are converted to and from UTF-8 |
| OBJECT IDENTIFIER, RELATIVE-OID | `[]uint64` of arcs |
| SEQUENCE | `struct`, one field per member |
| SET | `struct`, like SEQUENCE (the codec writes canonical order) |
| CHOICE | `struct` with `Present <T>Pr` and one pointer field per alternative; constants `<T>Pr<Alt>` |
| SEQUENCE OF | `[]Elem`; a named type is `type T []Elem`. An inline element type is named `<Owner>Member` |
| SET OF | `[]Elem`, like SEQUENCE OF; Encode sorts the elements into canonical order (X.691 22.1), so an unsorted slice comes back sorted from Decode |
| Inline SEQUENCE / CHOICE | a named type `<Parent><Member>` (`<Choice><Alt>` for an alternative), one more segment per nesting level |
| OPTIONAL member | pointer (`*T`); `nil` = absent |
| Extension addition | always a pointer, `OPTIONAL` or not; `nil` = absent |
| `[[ ]]` group | one field `Ext<N> *<T>Ext<N>`, N counting the groups of that SEQUENCE from 1 |
| DEFAULT member | plain value plus an exported `<Type><Field>Default` constant (or `var`) |

Unnamed leaf elements of a SEQUENCE OF map as `[]int64`, `[]bool`, `[]float64`,
`[][]byte`, `[]BitString`, `[]string`, `[][]uint64`, `[]struct{}`. ENUMERATED
inline elements are `type <Owner>Member int32`; SEQUENCE and CHOICE elements are
`type <Owner>Member struct {...}`; a nested SEQUENCE OF is
`type <Owner>Member []Elem`, with `<Owner>MemberMember` one level deeper.
`<Owner>` is the type for `T ::= SEQUENCE OF ...` (`TMember`) and
`<Type><Member>` for a member or alternative `a` of `T` (`TAMember`). All
generated names are checked for collisions in one package namespace: a clash
(e.g. `TMember ::= BOOLEAN` next to an inline element of `T`) fails generation.

**Inline members** are named after their position and are held by value when
required, by pointer when OPTIONAL or a CHOICE alternative:

```asn1
T ::= SEQUENCE { a SEQUENCE { x INTEGER (0..3) } OPTIONAL, b BOOLEAN }
U ::= CHOICE { a CHOICE { x INTEGER (0..3), y BOOLEAN }, b BOOLEAN }
```

```go
type T struct { A *TA; B bool }     // *TA: OPTIONAL
type TA struct { X int64 }
type U struct { Present UPr; A *UA; B *bool }   // every alternative is a pointer
type UA struct { Present UAPr; X *int64; Y *bool }
```

**CHOICE alternative named `present`.** The discriminant `Present` is public
API, so an alternative whose Go name would be `Present` becomes `PresentAlt`;
its `Pr` constant keeps the plain name:

```go
// T ::= CHOICE { present INTEGER (0..3), b BOOLEAN }
type T struct { Present TPr; PresentAlt *int64; B *bool }
const TPrPresent TPr = 1
```

**Extension additions** can be absent whenever the sender implements an older
version of the spec, so they are pointers:

```asn1
T ::= SEQUENCE { a INTEGER (0..3), ..., b BOOLEAN, c INTEGER (0..7) }
```
```go
type T struct { A int64; B *bool; C *int64 }
```

`Decode` leaves an addition `nil` when it was not sent; `Encode` of a `nil`
addition encodes it as absent without error. An addition with a DEFAULT is a
plain value instead (see below). A nil `[[ ]]` group is absent on `Encode` and
an absent group decodes to nil. A `[[ ]]` group in a CHOICE is a syntax error
in asn1c itself.

**Named bits.** The constants are `int` bit positions in declaration order, e.g.
`CapsA int = 0`. Set bit n with `bs.Bytes[n/8] |= 0x80 >> (n % 8)`. In an enumerator or named-bit list, two names that differ only by a hyphen before a digit (`d1`, `d-1`) become `D1` and `D_1`: the clashing name keeps its `_` before the digit. The same holds for SEQUENCE fields, CHOICE alternatives, type names and typed value names (`a1`, `a-1` become `A1` and `A_1`; the inline type, the `<Choice>Pr<Alt>` constant and the DEFAULT constant follow). A DEFAULT of
a named-bit BIT STRING is refused.

**DEFAULT members.** Supported forms:

- BOOLEAN, INTEGER and ENUMERATED with a plain integer / `TRUE` / `FALSE` /
  enumerator value (also through a type reference);
- every character string type and the two time types (UTCTime,
  GeneralizedTime) with a quoted string (a plain `string` in Go; the bytes are
  the literal as written, UTF-8 for UTF8String);
- OCTET STRING with an `'..'H` / `'..'B` value of whole octets, and a BIT STRING
  (no named bits) with an `'..'H` / `'..'B` value;
- NULL with `NULL` (the member is `struct{}`; a present NULL always equals the
  DEFAULT, so it is never encoded);
- REAL with a decimal number (`1.5`, `-2.25`, `1e3`), an integer (`0`), or
  `PLUS-INFINITY`, `MINUS-INFINITY`, `NOT-A-NUMBER` (a `float64`). The value is
  compared exactly: NaN equals NaN, and `-0.0` is not the DEFAULT `0` (they are
  two REAL values with different encodings). Go has no constant for an
  infinity, NaN or minus zero, so for those the exported declaration is a
  `var` computed at start-up.

Every other form (REAL as `{ mantissa M, base B, exponent E }`, OID,
SEQUENCE / CHOICE / SEQUENCE OF values, named-bit BIT STRING, ...) is refused
at generation with exit 70, because the C generator would silently treat the
member as OPTIONAL.

```go
type DefaultsPDU struct {
    Flag  bool       // BOOLEAN DEFAULT TRUE
    Small int64      // INTEGER (0..7) DEFAULT 0
    Name  string     // PrintableString DEFAULT "hi"
    Octs  []byte     // OCTET STRING DEFAULT 'AB'H
    Bits  BitString  // BIT STRING DEFAULT '101'B
}
```

- `Decode` yields the effective value: an absent member (or extension addition)
  comes back holding its DEFAULT.
- `Encode` leaves out a member equal to its DEFAULT; Go cannot tell "absent"
  from "equal to the default".
- **The Go zero value is not the DEFAULT.** `T{}` holds `false` / `0` / `""` /
  `nil` even where the DEFAULT is `TRUE`, `5` or `"hi"`, and `Encode` sends what
  the field holds. Set DEFAULT fields explicitly, using the exported
  `<StructGoName><FieldGoName>Default` declaration next to the struct
  (`DefaultsPDUFlagDefault`; a typed `const`, or a `var` for OCTET STRING and
  BIT STRING, which you must not modify).

**OBJECT IDENTIFIER and RELATIVE-OID.** `type T []uint64` when named,
`*[]uint64` for an OPTIONAL member or CHOICE alternative. An arc is at most
4294967295 (the C runtime's arc type is 32 bits); `Encode` returns
`rt.ErrConstraint` for a larger arc and for what `OBJECT_IDENTIFIER_set_arcs`
rejects: fewer than two arcs (including an empty or nil slice), a first arc
above 2, a second arc of 40 or more when the first is 0 or 1, and a second arc
above 4294967215 when the first is 2. A RELATIVE-OID takes any number of arcs,
including none. `Decode` returns `rt.ErrDecode` for contents octets that are not
a valid arc encoding.

**Strings.** A BMPString or UniversalString value that is not valid UTF-8, or a
BMPString character above U+FFFF, makes `Encode` return `rt.ErrConstraint`; a C
buffer that is not valid Unicode makes `Decode` return `rt.ErrDecode`. SIZE,
FROM, NumericString and time-syntax checks are the C runtime's and surface from
`Encode` as errors.

**Wide INTEGER and the C runtime.** The C PER codec keeps constraint bounds in a
`long`, so it cannot encode a present value of a type like
`INTEGER (0..18446744073709551615)`; `Encode` returns the same error as
`converter-example` (KNOWN-ISSUES #1). Ranges that exceed 32 bits but fit a
`long`, such as `INTEGER (0..1099511627775)`, encode fine.

## Not supported

ANY, EXTERNAL, EMBEDDED PDV, CHARACTER STRING, an open-type (information
object class `&Value`) member of a SET (KNOWN-ISSUES #25), the DEFAULT forms
listed above, and an INTEGER range that fits neither `int64` nor `uint64` are
refused at generation with an `asn1cgo: ...` message and exit 70. A bare
`TYPE-IDENTIFIER.&Type` outside an object-set-governed field is not refused but
generates an empty union; do not use it. For bugs and open limitations see
[KNOWN-ISSUES.md](KNOWN-ISSUES.md).

## Runtime module

Generated code imports the runtime module (error model, arena allocator and a
copy of the asn1c skeleton codec). Its source is `libasn1compiler_go/rt/go`.

- **Module path:** `github.com/Frozen-Potato/asn1c/libasn1compiler_go/rt/go`;
  `ASN1CGO_GO_MODULE_PREFIX` does not change it.
- **Fetch (default).** The generated `go.mod` has a plain `require` at the
  generator's version (`v0.3.2`). Run `go mod tidy` once after generation
  (network or `GOPROXY` needed) to write `go.sum`; until then `go build` stops
  with `missing go.sum entry`. Commit `go.sum`. Regenerating rewrites `go.mod`
  but not `go.sum`.
- **Local.** `ASN1CGO_RT_LOCAL=<dir>` points at a runtime checkout (its `go.mod`
  must declare the module path above, else exit 70). The generator adds a
  `replace` to `go.mod` and lists `<dir>` in `go.work`; no `go.sum` entry is
  needed.
- **Release.** The runtime is versioned in lockstep with the generator: bump
  `ASN1CGO_RT_VERSION` in `go_entry.c` (and the version text in
  `rt/go/README.md`), commit, tag that commit
  `libasn1compiler_go/rt/go/vX.Y.Z` and push the tag. A generated tree is only
  fetchable once the tag exists. After changing `skeletons/`, refresh the
  runtime's copies with `libasn1compiler_go/rt/sync-skeletons.sh`.
- **Installed asn1c.** `make install` puts the runtime C files the generator
  copies into every tree in `<pkgdatadir>/go-rt`; with the default `-S`
  directory no `ASN1CGO_RT_SRC` is needed.

Upgrading from runtime v0.2.x (`asn1cgo-rt`): regenerate every tree, change
hand-written imports of `…/asn1cgo-rt/rt` to
`github.com/Frozen-Potato/asn1c/libasn1compiler_go/rt/go/rt`, run `go mod tidy`
(or set `ASN1CGO_RT_LOCAL`), and delete the old `asn1cgo-rt` copy.

## Environment variables

| Variable | Effect |
|---|---|
| `ASN1C_DESTDIR` | Source of the C tree copied into `<go-outdir>/internal/cspec`; default: the `-D` directory. |
| `ASN1C_PREFIX` | Per-run C symbol prefix (e.g. `EX_`); Go names stay prefix-free. |
| `ASN1CGO_FORK_SKEL` | Override of the skeletons directory (default: the `-S` path). |
| `ASN1CGO_RT_LOCAL` | Runtime checkout directory; selects local mode (see Runtime module). Unset: fetch mode. |
| `ASN1CGO_RT_SRC` | Override of the runtime C source directory copied into each tree. |
| `ASN1CGO_GO_MODULE_PREFIX` | Module path prefix for the generated modules. Does not affect the runtime module path. |
| `ASN1CGO_DUMP_NAMES` | Write the identifier name rows (module, kind, C id, Go name) to the named file. |
| `ASN1CGO_DUMP_COVERAGE` | Write the per-kind construct coverage tally to the named file. |
| `ASN1CGO_DUMP_CHOICE_ALTS` | Print the running maximum CHOICE alternative / extension-index counts. |
| `ASN1CGO_FLATDBG` | Trace the layout engine (debugging). |

## Platform and limits

- **amd64 only**: every generated `.go` file carries `//go:build amd64`.
- **Depth**: 64 depth units per encode/decode (`ASN1CGO_MAX_DEPTH` in the
  runtime's `rt/err.h`; changing it means regenerating the trees).
- **C stack guard**: each decode runs with a stack guard of
  `ASN1CGO_C_STACK_MAX` bytes (default 96 KiB; override with
  `-DASN1CGO_C_STACK_MAX=<bytes>`, nonzero), so a hostile deeply nested input
  is rejected during C decoding. The trip is an ordinary C decode failure and
  surfaces as `ErrDecode`, not `ErrDepth`. Lower it only for small thread
  stacks, and not below what your deepest recursive type needs.

## Tests

All scripts live in `tests/` and exit 77 (skipped) when `go`, cgo, linux/amd64
or the built `asn1c` is missing.

- `run-e2e.sh`: generates Go from the e2e specs, builds it with cgo and runs
  round-trip, per-error-code and allocation-fault tests, with and without
  `-no-gen-OER`.
- `run-feature-matrix.sh`: generates every `feature-matrix/*.asn`, runs `go vet`
  and compares the outcome (OK / REFUSED / KNOWN-BROKEN) with `expected.tsv`.
- `run-c-invariance.sh`: checks that adding `-Fgo=` leaves the generated C
  byte-identical (apart from the stamped command line).
- `run-gowork-race.sh`: parallel generators into sibling `-Fgo` dirs must all
  end up in the shared `go.work`.
- `run-rt-fetch.sh`: fetch mode against a `file://` `GOPROXY`: build fails
  before `go mod tidy`, works after.
- `run-rt-skeleton-sync.sh`: the runtime's C files equal `skeletons/` and
  compile warning-free.
- `run-stdlib-names.sh`: the generator's standard-library name table matches
  `go list std`.
