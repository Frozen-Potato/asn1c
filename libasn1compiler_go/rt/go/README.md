# asn1cgo-rt

`asn1cgo-rt` is the runtime module for code generated by
[asn1cgo](..) — the Go backend of the asn1c compiler fork. Every
generated spec module imports it; the generated code cannot build
without it.

It contains:

- the shared Go error model (`rt/errors.go`): the `Error` type, the
  `Code` constants, and one exported sentinel per code;
- the conversion runtime the generated C calls into (`arena.c`,
  `err.c`, `buf.c`, and their headers): the arena allocator that owns
  all flat-memory for one call, the error struct, and the encode
  buffer;
- the asn1c skeleton runtime (`rt/*.c`, `rt/*.h`) — the APER/XER codec
  the generated code drives. It is Free software; its license is in
  the `LICENSE` file beside this README.

## Requirements

- Linux, amd64
- CGO enabled (`CGO_ENABLED=1`) and a C compiler (gcc or clang)

## The error model

Every generated `Encode`/`Decode` returns `*rt.Error` on failure:

```go
type Error struct {
    Code     Code    // int32-typed, one const per C asn1cgo_err_code
    TypeName string  // innermost ASN.1 type
    Field    string  // innermost member, "" at the PDU root
    Message  string  // constraint path or codec message
}
```

Match failures with `errors.Is` against the sentinels; a sentinel
matches an `*Error` returned by ANY spec package:

```go
_, err := e2ap_pdu_descriptions.DecodeE2APPDU(buf)
switch {
case errors.Is(err, asn1cgort.ErrDecode):
    // malformed bytes; a structure the codec rejected
case errors.Is(err, asn1cgort.ErrTrailing):
    // valid PDU, bytes left after it
case errors.Is(err, asn1cgort.ErrConstraint):
    // value outside a declared range/size bound
case err != nil:
    // anything else (see Error.Code)
}
```

The codes: `ErrArg`, `ErrAlloc`, `ErrConstraint`, `ErrEncode`,
`ErrDecode`, `ErrTrailing`, `ErrChoiceNothing`, `ErrChoiceBad`,
`ErrIOCUnknown`, `ErrIOCMismatch`, `ErrDepth`, `ErrInternal`.

`errors.As(err, &e)` gives the full `*Error` (type, field, message)
when the failure site matters.

The package also exposes the deterministic allocation-fault hooks the
generated code's tests use (`ArenaBalance`, `ArenaFailAt`,
`ArenaEvents`). Consumer code ordinarily never needs them; they exist
so a build can prove every error path frees its arena.

## Layout

```
asn1cgo-rt/
  go.mod          module asn1cgo-rt (the release republishes it under
                  its own prefix; the module line is the only delta)
  README.md       this file
  LICENSE         the asn1c upstream license (the skeleton runtime)
  rt/
    errors.go     the Go error model + the one cgo surface
    arena.c/.h    the chunked arena allocator
    err.c/.h      the C error struct and codes
    buf.c         the encode-buffer free routine
    types.h       shared flat-type declarations
    ...           the asn1c skeleton runtime subset
```

## Versioning

The module is versioned in lockstep with the generator: the generator
embeds one version string and every generated `go.mod` requires the rt
module at exactly that version. Pick the pair together; a generated
tree pins the matching rt in its `require` line.
