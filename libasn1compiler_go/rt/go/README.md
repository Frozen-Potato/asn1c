# asn1cgo runtime

This module (`github.com/Frozen-Potato/asn1c/libasn1compiler_go/rt/go`) is the runtime module for code generated by
[asn1cgo](..) — the Go backend of the asn1c compiler fork. Every
generated spec module imports it; the generated code cannot build
without it.

It contains:

- the shared Go error model (`rt/errors.go`): the `Error` type, the
  `Code` constants, and one exported sentinel per code;
- the conversion runtime the generated C calls into (`arena.c`,
  `err.c`, `buf.c`, and their headers): the arena allocator that owns
  all flat-memory for one call, the error struct, and the encode
  buffer;
- a copy of the asn1c skeleton runtime (every `skeletons/*.c`/`*.h` of the
  fork except `converter-example.c`, in `rt/`) — the APER/XER codec the
  generated code drives. It is refreshed from the fork by
  `libasn1compiler_go/rt/sync-skeletons.sh`; do not edit the copies. Its
  license is in the `LICENSE` file beside this README.
- OER: the module defines `ASN_DISABLE_OER_SUPPORT` by default (matching
  trees generated with `-no-gen-OER`, and keeping the OER-only sources out of
  the build). Trees generated with OER enabled also build and work for APER
  without any tag. `-tags asn1cgo_oer` only compiles the runtime's OER codec
  in; the generated Go API is APER-only, so this matters only if you call the
  C OER functions yourself.

## Requirements

- Linux, amd64
- CGO enabled (`CGO_ENABLED=1`) and a C compiler (gcc or clang)

## The error model

Every generated `Encode`/`Decode` returns `*rt.Error` on failure:

```go
type Error struct {
    Code     Code    // int32-typed, one const per C asn1cgo_err_code
    TypeName string  // innermost ASN.1 type
    Field    string  // innermost member, "" at the PDU root
    Message  string  // constraint path or codec message
}
```

Match failures with `errors.Is` against the sentinels; a sentinel
matches an `*Error` returned by ANY spec package:

```go
_, err := example.DecodeExamplePDU(buf)
switch {
case errors.Is(err, rt.ErrDecode):
    // malformed bytes; a structure the codec rejected
case errors.Is(err, rt.ErrTrailing):
    // valid PDU, bytes left after it
case errors.Is(err, rt.ErrConstraint):
    // value outside a declared range/size bound
case err != nil:
    // anything else (see Error.Code)
}
```

The codes: `ErrArg`, `ErrAlloc`, `ErrConstraint`, `ErrEncode`,
`ErrDecode`, `ErrTrailing`, `ErrChoiceNothing`, `ErrChoiceBad`,
`ErrIOCUnknown`, `ErrIOCMismatch`, `ErrDepth`, `ErrInternal`.

**Which codes occur where.**

| Code | Encode | Decode |
|------|--------|--------|
| `ErrArg` | nil receiver | **nil or empty input** (`Decode(nil)`, `Decode([]byte{})`) |
| `ErrAlloc` | yes (see the encoder-OOM note below) | yes |
| `ErrConstraint` | value outside a declared range/size/alphabet | decoded value violates a constraint |
| `ErrEncode` | the APER encoder failed | never |
| `ErrDecode` | never | malformed bytes, including an IE id the spec's object set does not list |
| `ErrTrailing` | never | bytes left after the PDU |
| `ErrChoiceNothing`, `ErrChoiceBad` | a CHOICE with no / an invalid `Present` | defensive only (the codec never yields these) |
| `ErrIOCUnknown` | the IE id is not in the governing object set | defensive only; an unknown id is rejected earlier as `ErrDecode` |
| `ErrIOCMismatch` | the id is known, but the value's `Present` is not the alternative that id governs | defensive only |
| `ErrDepth` | recursion budget exceeded | recursion budget exceeded |
| `ErrInternal` | a bug in the generator or runtime | same |

`ErrInternal` is never caused by caller input: it means a generator
invariant was violated at run time. Please report it, with the spec.

On encode, the IE id is checked against the object set first
(`ErrIOCUnknown`); only a known id is then compared with the selected
alternative (`ErrIOCMismatch`).

**Encoder out-of-memory is reported as `ErrEncode`.** If asn1c's own
encoder runs out of memory while producing the output buffer, the
failure surfaces as `ErrEncode`, not `ErrAlloc`: the encoder reports
only that it failed. `ErrAlloc` covers the allocations made by the
generated conversion code and the runtime arena.

`errors.As(err, &e)` gives the full `*Error` (type, field, message)
when the failure site matters.

The package also exposes the deterministic allocation-fault hooks the
generated code's tests use (`ArenaBalance`, `ArenaFailAt`,
`ArenaEvents`). Consumer code ordinarily never needs them; they exist
so a build can prove every error path frees its arena.

## Layout

```
rt/go/            (the module root, tagged libasn1compiler_go/rt/go/vX.Y.Z)
  go.mod          module github.com/Frozen-Potato/asn1c/libasn1compiler_go/rt/go
  README.md       this file
  LICENSE         the asn1c upstream license (the skeleton runtime)
  rt/
    errors.go     the Go error model + the one cgo surface
    arena.c/.h    the chunked arena allocator
    err.c/.h      the C error struct and codes
    buf.c         the encode-buffer free routine
    types.h       shared flat-type declarations
    ...           the asn1c skeleton runtime (copied from skeletons/)
```

## Versioning

The module is versioned in lockstep with the generator: the generator
embeds one version string and every generated `go.mod` requires the rt
module at exactly that version. Pick the pair together; a generated
tree pins the matching rt in its `require` line.
